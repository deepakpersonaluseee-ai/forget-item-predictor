# Forget Item Predictor — Marketing Website

> **Context-Aware AI Smart Checklist & Habit Prediction Engine**

## 💻 How to Run Locally

You can run this project with zero build dependencies:

### Option 1: Direct Browser Launch
Simply double-click `index.html` in your file explorer to open it in any modern browser (Chrome, Edge, Safari, Firefox).

### Option 2: Python HTTP Server (Already active)
```bash
python -m http.server 8080
```
Then visit [http://localhost:8080](http://localhost:8080) in your browser.

## 📱 Responsiveness
The site is built mobile-first:
- **Desktop (≥1024px)**: Full multi-column grids, interactive cards, side-by-side mockups.
- **Tablet (768px – 1023px)**: Responsive 2-column grids with adjusted spacing.
- **Mobile (<768px)**: Seamless vertical stacking, touch-friendly hamburger drawer menu, and horizontally scrollable comparison matrix.
